# Linux

1. Install Arch Linux  
2. Install drivers (audio and video)  
3. Install a desktop environment  
4. Install the necessary packages  

## Layout

| Path | Contents |
| --- | --- |
| `pc/` | Desktop PC install notes (`archinstall.md`) |
| `lap/` | Laptop install notes, plus touchpad gestures (`config.yaml`, `kwingesturesrc`) |
| `vm/` | VirtualBox install notes and `archinstall` config (`config.json`) |
| root | Shared dotfiles and package lists (`.bashrc`, `alacritty.toml`, `nvim/`, `vscode/`, `archpackages.txt`, `kde-plasma.txt`) |
